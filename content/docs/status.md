## Source is available

The [NaguMIX application source](https://github.com/nagumix/nagumix) is public.
To run it with Python 3.12 and uv, follow [Getting Started]({{< relref "getting-started.md" >}})
and the repository's current setup instructions.

## Packaged downloads

Packaged downloads are not yet available. There is no public Windows installer
or signed application download, and no macOS or Linux binary download to offer.

Source availability does not establish that every operating system or hardware
configuration is supported. Native runtime requirements depend on the host;
consult the application repository before setting up a source environment.
