## NaguMIX 0.5.0 for Windows

[Download Windows x64 setup](https://github.com/nagumix/nagumix/releases/download/v0.5.0/NaguMIX-0.5.0-windows-x64-setup.exe)
for a per-user installation. The application and installers are unsigned, so
Windows may show an unrecognized-app warning. No development Python is required.
See [Getting Started]({{< relref "getting-started.md" >}}) for the runtime requirement
and setup choices.

| Download | Use it for |
| --- | --- |
| [Setup EXE](https://github.com/nagumix/nagumix/releases/download/v0.5.0/NaguMIX-0.5.0-windows-x64-setup.exe) | Interactive per-user installation with prerequisite detection |
| [Portable ZIP](https://github.com/nagumix/nagumix/releases/download/v0.5.0/NaguMIX-0.5.0-windows-x64.zip) | Extract the complete folder and keep all its files together |
| [MSI](https://github.com/nagumix/nagumix/releases/download/v0.5.0/NaguMIX-0.5.0-windows-x64.msi) | Per-user installation when the required x64 runtime is already present |
| [SHA-256 checksums](https://github.com/nagumix/nagumix/releases/download/v0.5.0/SHA256SUMS.txt) | Verify the downloaded source or Windows package |
| [Matching source ZIP](https://github.com/nagumix/nagumix/releases/download/v0.5.0/NaguMIX-0.5.0-source.zip) | Source accompanying these packages |

Read the [0.5.0 release notes]({{< relref "release-0.5.0.md" >}}) and
[full release record](https://github.com/nagumix/nagumix/releases/tag/v0.5.0).
There are no macOS/Linux binaries or published WinGet package for this release.
Upgrade, offline installation and reboot scenarios have not been validated.
Availability does not establish support for every Windows or hardware configuration.

## Run from source

The [v0.5.0 application source](https://github.com/nagumix/nagumix/tree/v0.5.0)
is public. Follow [Getting Started]({{< relref "getting-started.md" >}}) and the
[versioned setup instructions](https://github.com/nagumix/nagumix/blob/v0.5.0/README.md#development-setup)
for Python 3.12, uv and your platform's native prerequisites.
